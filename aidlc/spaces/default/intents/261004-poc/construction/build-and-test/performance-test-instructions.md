# Performance Test Instructions — BusNetwork Portal POC

## Applicability

No performance tests apply. The approved requirements say explicitly that no performance, availability, localisation, accessibility or security targets apply to this POC (`inception/requirements-analysis/requirements.md`, Non-Functional Requirements). The active test strategy is Minimal, and the workflow has no Performance Validation stage.

## How to Run

Nothing to run. If a later release adopts the BRD's performance target (NFR-01: list page under 2 s at p95 for 50 000 trips), it needs its own load test against a real data store. The in-memory POC cannot represent that target.

## Expected Coverage

Not applicable.
